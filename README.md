# Hoa Kiều Linh — Mindloop Dark / Trippy Edition

Bản remake landing page Hoa Kiều Linh dựa trên cấu trúc và motion language của reference **Mindloop**, kết hợp tinh thần immersive/trippy từ video Organimo đã cung cấp trước đó.

## Stack
- React + Vite + TypeScript
- Tailwind CSS
- shadcn-style UI primitives (`Button`, `Input`)
- Framer Motion
- hls.js
- lucide-react
- Inter + Instrument Serif

## Design direction
- Pure black / white monochrome
- Liquid glass UI
- Fullscreen moving media
- Triple-echo typography (3 lớp chữ lệch nhẹ, hoàn toàn monochrome)
- Scroll word reveal
- HLS video CTA
- Toàn bộ nội dung chỉ nói về **Hoa Ly**

## Chạy local
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Nội dung thương hiệu
- Hoa Kiều Linh
- Tòa GS3, Vinhomes Smart City, Tây Mỗ, Hà Nội
- Chỉ kinh doanh Hoa Ly
- High quality / LGBTQ+ friendly / women-owned

## Lưu ý
Các video trong bản prototype đang dùng URL media của reference mà người dùng cung cấp để giữ đúng motion/atmosphere. Khi đưa production, nên thay bằng video macro Hoa Ly / bó hoa thật của Hoa Kiều Linh để thương hiệu nhất quán và giảm phụ thuộc bên ngoài.
